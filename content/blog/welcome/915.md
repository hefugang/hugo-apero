This site is built with the [Hugo Apéro](https://github.com/hugo-apero/hugo-apero)
theme and deployed to Netlify directly from this GitHub repository.

## How updates work

1. Edit or add Markdown files under `content/`.
2. Commit and push to GitHub.
3. Netlify detects the push, rebuilds, and republishes — usually in under a minute.

No build step on your machine is required. To preview locally you only need
[Git](https://git-scm.com/) and [Hugo (extended)](https://gohugo.io/installation/).
